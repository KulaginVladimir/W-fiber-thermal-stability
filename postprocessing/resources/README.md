# Input data for the two-temperature model

`Ce_W.dat` and `G_W.dat` contain the electronic heat capacity and electron–phonon coupling factor of tungsten, respectively.

Source: Z. Lin, L. V. Zhigilei, V. Celli, Physical Review B 77 (2008) 075133.

- Article: https://doi.org/10.1103/PhysRevB.77.075133
- Tabulated data: https://faculty.virginia.edu/CompMat/electron-phonon-coupling/
